# Store metadata (draft)

Source of truth for App Store Connect and Google Play Console text. Nothing
here is uploaded automatically; paste it in, or wire `eas metadata` later.
Every claim in `privacy.md` is traced to code — change the code, change the
label in the same PR.

| File | Where it goes |
|---|---|
| `listing.en.md`, `listing.de.md` | Name, subtitle/short description, description, keywords |
| `privacy.md` | App Store "App Privacy" + Play "Data safety" |
| `rating.md` | Age-rating questionnaires |
| `review-notes.md` | App Review notes / Play app-access instructions |

Open decisions are marked **DECISION** and listed at the end of each file.
