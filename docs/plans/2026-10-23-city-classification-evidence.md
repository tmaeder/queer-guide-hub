# Corroborated city classification recovery

The read-only collector examines existing Wikidata identities whose original machine audit says `No corroborated settlement classification`. It requires a current matching name or alias, country ISO code, one Earth coordinate within 10 km, and complete class labels accepted by the existing settlement classifier. Ended claims, subdivisions, non-place classes and ambiguous coordinates remain unresolved. Official responses have bounded sizes/timeouts and retained timestamps and hashes.

Of 125 eligible records, 16 had positive evidence and 109 remained unresolved. The default-dry SQL operator requires unchanged city timestamps, identity, original classification and geography fingerprint, and excludes human ownership of the relevant fields. It replaces only the machine classification provenance, then calls the existing geography verification and evidence RPCs. Native polygon checks remain decisive. It neither invokes city-quality synchronization nor changes publication, names, coordinates, countries, verification dates or unrelated provenance.

Production rollback assertions passed before committing the same guarded batch. Fifteen geography records became verified through the native RPCs. Hatillo remains in review: its polygon is Puerto Rico (`PR`), while its assigned country is `US`. The explicit native territory-parent rule maps PR to US, but that does not itself satisfy the current polygon verification rule. Its decision page now includes the specific mismatch and official [Puerto Rico municipality directory](https://www.pr.gov/directorio-municipos/hatillo) and [Census profile](https://data.census.gov/profile?g=050XX00US72065). No country reassignment or polygon waiver was applied.

Validation: three collector regression tests and seven existing settlement classifier tests pass, along with Deno checking and scoped lint. The operator verifies whole city records, allowing only the classification provenance and native update timestamp to change. Replaying an already applied proof cannot select the changed record.
