# Source-confirmed missing city identities

The active unresolved-classification cohort contained 885 cities, including 630 without a Wikidata identity (612 real records and 18 ghosts). Repeating the previous resolver's no-match/ambiguous searches would not establish new evidence. Exported the 126 real Canadian/US records, their current fingerprints and complete baseline snapshots, then ran fresh bounded Wikidata name searches and the existing named/country/coordinate/class evidence collector.

Discovery requires a complete search page with fewer than 50 hits and no continuation marker. Every hit is corroborated using current names/aliases, current country, one Earth coordinate and a positive explicit settlement/municipal class. Accept exactly one corroborated candidate within two kilometres; competing identities, duplicate proofs, missing/invalid coordinates and dissolved entities refuse. Preserve the full search response/hash/time plus entity source capture. The existing collector now exports its collection function so discovery uses exactly the same source rules.

The first pass returned 11 apparent proofs. Inspection exposed an old classifier bug: its generic `township of ` expression treated county subdivisions as municipalities. Removed that broad exception. Retain only precise Pennsylvania/New Jersey township municipal forms alongside previously recognized charter/Canadian forms, with historical/subdivision conflicts still refused. Nine container matches were rejected; Big Eddy (Q16841709) and Worcester Township (Q10748506) retained their proofs. No rejected record was written.

Semantic references:
- [Census definitions of minor civil divisions](https://www.census.gov/programs-surveys/popest/about/glossary/geo-terms.html) distinguish county subdivisions from incorporated places.
- [Census municipal/township government definitions](https://www.census.gov/content/dam/Census/library/publications/2012/econ/2012isd.pdf) explain that a township government can administer an area without proving a population concentration.
- [Pennsylvania municipal directory](https://dced.pa.gov/local-government/municipal-statistics/municipalities/) explicitly includes township municipalities.
- [New Jersey municipal classification](https://www.nj.gov/treasury/taxation/pdf/assessorshandbook.pdf), sections 101.06–101.07, lists township as a municipal type.
- Identity captures: [Big Eddy](https://www.wikidata.org/wiki/Q16841709), [Worcester Township](https://www.wikidata.org/wiki/Q10748506).

An initial native rollback rehearsal admitted zero records. Diagnostics showed that `CITY_IDENTITY_AMBIGUOUS` has a machine-generated `hard_blocker=true` from `city_quality_profile`. That means the missing identity blocks publication; it does not establish human ownership of the identity field. The operator now permits only this exact pending machine signal, with matching city name/slug, `publication_ready=false` and only its known generated metadata keys. Other blockers, unknown/extra metadata, human reviews, force/confirmation/manual holds and resolved attribution refuse. Lock and recheck the review rows before any mutation. Publication settings and review rows remain unchanged during factual repair.

The native operator installs no permanent schema. Require current row timestamp and geography fingerprint, exact previous unresolved machine classification, an unlinked canonical record, no competing native name/QID, valid source hashes/timestamps, the two-kilometre bound and the native country polygon. Set only the external identity and its classification/source provenance. Run native geography verification and evidence recording, assert every other city field and unrelated provenance unchanged, and retain complete before/after audits. Pause and internal-actor guards apply. The bounded Node runner writes atomic receipts, refuses existing output paths and never retries an unknown write.

A second rollback rehearsal admitted both records. Apply committed two identity repairs; independent native checks confirmed both expected QIDs, verified geography, unchanged protected projections and unchanged review rows, plus one full city audit each. A repeat dry run admitted zero. The native quality profile then reported no identity issue or other blockers for either city. This retained full review before/after audits and no human attribution. After refreshing the worklist, both cities had zero active cases and zero pending identity findings: **two actual cases removed**. The global count was 5,742; concurrent ingestion means this is not a two-case aggregate decrease.
