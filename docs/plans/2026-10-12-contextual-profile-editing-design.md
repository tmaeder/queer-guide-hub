# Contextual personal-profile editing

Approved by the user on October 12, 2026.

- The personal profile is the authoritative home for personal information and its editors. Reuse its existing header, status controls, and public/community/self visibility preview.
- Put edit and visibility actions beside displayed profile sections. Open one relevant editor inline within the profile, with the original autosave, retry, and session-expiry behavior. Remove the duplicate settings identity preview and settings accordion index.
- Keep travel preferences within the existing Travel tab. Keep username, credentials, notifications, account deletion, and legacy personal documents in an owner-only Account tab. Provide a consolidated privacy editor in the profile.
- Remove Settings from hub navigation. Redirect all old settings URLs to the authenticated owner's appropriate profile editor or tab, retaining supported locales and useful query parameters.
- Visitors and preview lenses never mount private editors or account controls. Profile ownership must agree with the authenticated user ID.
- Preserve pending form changes when closing an editor or switching profile tabs. Verify autosave and recovery, routing, owner/visitor/lens boundaries, and desktop/mobile layout.

This extends the incumbent paper/ink subway design system. It does not change profile storage, public-profile authorization, or the hub's community/connection/personal destinations.
